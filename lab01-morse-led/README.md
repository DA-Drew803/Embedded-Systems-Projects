# Lab 01 - Morse LED Encoder

Encodes a string as Morse code and flashes it through the on-board LED. A
the original conditional character encoder.

## Concepts

- Character mapping and string traversal
- Morse timing based on a 200 ms unit

## Wiring

No external wiring is required. The LED is connected to PB5 on the target
board. Change `message` in `main.c` to encode a different string.
